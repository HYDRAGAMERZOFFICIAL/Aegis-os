TACTICAL CYBER DEFENSE & BREACH RECOVERY TUTORIAL

How Adversaries Attack AegisOS

Adversaries deploy multi-stage attacks against the system:

  • Port Hijacking: Rogue daemons hijack ports (e.g. port 8443) to intercept ingress traffic. Use Diagnostics & Triage to kill rogue PIDs.
  • Capability Escalation: Signed binaries request unauthorized capabilities like CAP_NET_RAW_SOCKET. Use Aegis Shield to revoke tokens.
  • Ransomware Inode Corruption: Attackers corrupt file headers or encrypt vault data. Use File Recovery & Hex Carver to reconstruct them.

The 30-Second Critical Red Alert Lockdown

When an active emergency attack fails or a critical zero-day strikes, the system enters Critical Lockdown:

⚠️ YOU HAVE BEEN HACKED // SYSTEM SHUTS DOWN IN 30 SECONDS

A flashing red screen will count down. Click [⚡ FIX THE SYSTEM] and enter the emergency override cipher: AEGIS-OVERRIDE-SEC99 to defuse it!

Warning: If the 30-second timer hits zero, all local files are wiped and you must carve and recover them from memory!

How to Recover & Carve Corrupted Files

In Files & Storage, open the [🔬 File Recovery & Hex Carver] tab:

  • Select any corrupted file (e.g. financial_audit.db.corrupt).
  • Inspect the raw hex bytes and check the Forensic Clue.
  • Enter the repair magic header (e.g. 41 45 47 49 for AEGIS DB, or 7F 45 4C 46 for ELF drivers) or the decryption key (e.g. 0xAE915_KRN_SEC).
  • Click [Carve & Restore Inode] to restore the file cleanly!

Self-Healing Merkle Rollback

When multiple blocks are scrambled by ransomware, open Self-Healing Filesystem:

  • Click [Run Merkle Integrity Scan] to identify the diverged block.
  • Click [⚡ Rollback Checkpoint] to execute an atomic sub-10 second restoration to clean baseline chkpt-0001.
  • Or run checkpoint rollback in Terminal!

Operator Investigation Tools

  • Case Dossier (F4): Press F4 or click the Case Dossier pill to view objectives, review clues, and take on Live Drills!
